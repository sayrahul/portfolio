# Assets Folder

## 📁 Put These Files Here:

### Required:
1. **logo.png** - Your ProVenture logo (transparent background recommended)
2. **about.jpg** - Team photo or office photo for About section

### Optional:
- Any other images you want to use
- Favicon files
- Additional graphics

---

## 📐 Recommended Sizes:

- **logo.png**: 400px wide (transparent PNG)
- **about.jpg**: 1200x800px (landscape)

---

## 💡 Tips:

- Use PNG for logo (supports transparency)
- Use JPG for photos (smaller file size)
- Compress images before uploading (use tinypng.com)
- Keep file names simple (no spaces)
