# 📊 Google Sheet Template

## Copy this structure to your Google Sheet:

### **Column Headers (Row 1):**
```
A1: title
B1: description
C1: category
D1: type
E1: imageUrl
```

## **Categories:**
- `branding` - Logos, brand identity, packaging
- `web` - Website designs, UI/UX, apps
- `photo` - Photography, product photos, events
- `social` - Social media posts, ads, graphics
- `video` - Videos, motion graphics, reels

## **Types:**
- `image` - For images
- `video` - For videos (use YouTube embed URLs)

---

## **Image URL Format:**

### **For Images (Imgur):**
```
https://i.imgur.com/ABC123.jpg
```

### **For Videos (YouTube):**
```
https://www.youtube.com/embed/VIDEO_ID
```

---

## **Quick Start:**

1. Create new Google Sheet
2. Copy column headers (Row 1)
3. Add your project data (Row 2+)
4. Replace `imageUrl` with your Imgur URLs
5. Save sheet
6. Follow SETUP-GUIDE.md for Apps Script setup

---

## **Tips:**

- ✅ Keep titles short and descriptive
- ✅ Write clear descriptions (good for SEO)
- ✅ Use correct category names
- ✅ Test image URLs in browser first
- ✅ Add new rows anytime - updates automatically!
